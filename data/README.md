# Сырьё биржи для офлайн-расчётов

Здесь лежит кэш публичных данных Deribit, на котором считаются все исторические расчёты бота 2.
Он в репозитории намеренно.

**Почему не в .gitignore.** Данные невоспроизводимы. Архив Deribit со временем теряет глубину: он
отдаёт линейные опционы BTC_USDC только с 2025-08-06, SOL_USDC с 2024-02-12, а MATIC_USDC вообще
жил лишь с марта по август 2024. То есть перекачать сегодняшний срез через год будет уже нечем.
Всё остальное в проекте из этих данных выводится, а сами они первичны.

## Что внутри

| каталог | что | объём |
|---|---|---|
| `trades/<год>/` | лента сделок опционов по суткам, обратные (BTC-) и линейные (BTC_USDC-) | 568 МБ |
| `meta/` | календарь листинга инструментов, разложен по годам экспирации | 4.5 МБ |
| `candles/` | часовые свечи перпа и фьючерсов (форвард экспираций) | 8 МБ |
| `dvol/` | часовой индекс волатильности BTC (база условия У2) | 32 КБ |
| `funding/` | почасовая ставка фандинга перпа | 1.1 МБ |

Покрытие: 2021-08-09 .. 2026-08-13. JSON хранится сжатым, лента разложена по годам. Обе меры
приняты ради лимита GitHub в 100 МБ на файл: несжатая мета USDC весила 119 МБ.

## Как этим пользоваться

```bash
npm run hist:build -- --out /tmp/rec --from 2025-08-16 --to 2026-08-09
npm run hist:sellhedge -- --dir /tmp/rec --chain-adj 0.69
```

Скрипты находят кэш здесь автоматически. Готовые восстановленные записи лежат рядом, в
[`hist-records/`](hist-records/): пятилетнее окно собирается двадцать минут, и ждать его ради
перезапуска отчёта не надо. Свои записи (`--out`) можно класть куда угодно, в репозиторий они не
обязаны попадать: они производны от этого кэша.

Дозакачать новое (кэш дописывается, готовое не трогается):

```bash
npm run hist:download -- --from 2026-08-13 --to 2026-09-01
```
