# Обкатка сканера OTM, прогон 5: 72 часа, 4-7 августа 2026

Полная запись рынка и отчёты трёхсуточного наблюдательного прогона. Сделок не было: сканер
наблюдательный, ордера он не выставляет нигде и никогда.

## Что здесь

| файл | что это |
|---|---|
| `report-records.md` | распределения рынка целиком: премия, спред, тета по полосам дельты и срокам |
| `report-scan.md` | наши условия У1-У14: pass-rate, вырожденность, ворота обкатки |
| `eval-sell.md` | офлайн-оценка продажи волатильности, дельта 0.2, дальние сроки |
| `eval-sell-near.md` | то же для дельты 0.35 на ближних сроках |
| `dmitri-report-2026-08-07.md` | сводка для автора чеклиста, версия 1: подробная, с нашими обозначениями условий |
| `dmitri-report-2026-08-07-v2.md` | она же, версия 2: короткая, без внутренней терминологии, для отправки |
| `records.tar.gz` | сырьё, 96 МБ в распакованном виде |

## Сырьё

```bash
tar xzf records.tar.gz
```

Внутри `scan-records/` - NDJSON по суткам UTC, три тракта:

- **surface** - снимок ВСЕЙ поверхности опционов раз в 5 минут: 801 снимок, 399 730 строк.
  Каждая строка это инструмент: bid/ask/mark/mid, mark_iv, форвард своей экспирации, открытый
  интерес, объём, плюс посчитанные нами дельта, тета, вега.
- **ticks** - контекст уровня актива на каждом тике опроса (30 с): 8983 строки. RV7d, RV3d, σ1d,
  IV_ref и его источник, база DVOL, значения и состояния всех 14 условий, лучший кандидат,
  глубина книги финалистов.
- **checks** - сверка наших греков с биржевыми, 21 546 строк, двух видов: `leg` (точность формулы)
  и `surface` (формула плюс возраст пятиминутного снимка).

Расшифровка коротких ключей - в шапках `src/engine/otmscan/surface.js` и `tick-record.js`.

## Как воспроизвести анализ

```bash
tar xzf records.tar.gz && npm --prefix ../../../botLab-desktop run report:records -- --dir "$PWD"
```

Так же работают `report:scan` и `eval:sell` - все три читают запись и ничего в неё не пишут.

## Итог прогона

Сборка `dfa007c`, пресет `delta-v1`, 72.02 ч непрерывно, покрытие слотов 100%, деградаций и ошибок
ноль, битых строк ноль.

**Сигналов ноль.** Причина установлена числом: из двенадцати гейт-условий одиннадцать проходят почти
всегда (инструментная группа 99.6-100%), а блокируют ровно два, и оба порога лежат за границей того,
что рынок показывал за эти трое суток. У2 требует запаса недооценки IV в 5 пунктов при максимуме
+4.84; У6 требует бэквордации терм-структуры при максимуме −1.20, то есть нужный знак не возникал
ни разу.

Вместе с прогоном 3 (те же 72 часа в июле, противоположный режим рынка, тоже ноль сигналов) это
144 часа наблюдений в двух разных режимах с одинаковым исходом. Разбор - в
`dmitri-report-2026-08-07.md`.

## Зачем это в репозитории

Запись самодостаточна: по ней можно задним числом проверить ЛЮБОЙ набор порогов, не запуская
приложение и не обращаясь к бирже. Это и есть её ценность - все дальнейшие споры о калибровке
решаются счётом по этим файлам, а не новым трёхсуточным прогоном.
